# 夜貓子探險隊

給國小低年級小朋友和爸爸媽媽的台灣貓頭鷹與自然小網站，純靜態 HTML/CSS/JS，透過 GitHub Pages 發布。
網站採森林繪本風格：大字、大照片、「嗚嗚博士」貓頭鷹帶路，每頁底部有收合的「給爸爸媽媽」補充與資料來源。

| 頁面 | 內容 |
|---|---|
| `index.html` | 貓頭鷹是誰：大小、四個超能力、食繭、小測驗 |
| `taiwan-owls.html` | 7 種台灣貓頭鷹、牠們遇到的麻煩、我可以幫忙 |
| `where.html` | 去哪裡看貓頭鷹、夜觀小規則與背包清單 |
| `worksheet.html` | 可列印的貓頭鷹學習單（家長區附答案） |
| `nocturnal.html` | 台灣晚上的動物 |
| `birds.html` | 台灣的鳥：特有種、家門口的鳥、候鳥、公園賓果 |
| `pets.html` | 可以養貓頭鷹嗎？第一隻寵物建議 |
| `credits.html` | 照片作者與授權 |

- `assets/style.css`：版面樣式
- `assets/site.js`：選單、頁尾、嗚嗚博士插圖、照片載入、小測驗
- `assets/photos.js`：照片網址、作者與授權（皆來自 Wikimedia Commons）

內容整理於 2026 年 11 月；法規與活動資訊請以官方公告為準。
